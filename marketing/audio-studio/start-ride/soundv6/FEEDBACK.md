## What this is

Identical to soundv5 in every respect except the note data: same bass + voice-A layers,
same ride-only window (silent 0.0-5.3s, music 5.3-13.8s restarted from the theme's own
beginning, silent 13.8-14.0s finish hold). The only change is `voice_a.wav` was
regenerated from the corrected note list (the stray D5 blip is gone), so the C5-to-D5
move around 10s should now read as a clean two-note step instead of a three-note
stumble.

## What to listen for
