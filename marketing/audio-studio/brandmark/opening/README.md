## Sonic direction so far

"QUALIFIRE" wordmark reads clearly → a richer landing chord as the full mark +
tagline settle in. Uses the shared brand chime (see `../README.md` and
`../../synth.py`) so this, `../closing/`, and the teaser's bookends all sound like
the same brand. Full rationale in `soundv1/FEEDBACK.md`.
