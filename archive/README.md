| File | What it is |
|---|---|

| `cycles-002.md` | Compacted record of cycle 2. |

These predate `cycles/cycle-NNN.md`'s per-cycle-file convention and were compacted
here early on. Not read in the normal course of work — `STATE.md`/`NATHAN-STATUS.md`
give the current picture, `cycles/` gives the recent detailed record. Come here only
when tracing something back to the project's very first cycles.
