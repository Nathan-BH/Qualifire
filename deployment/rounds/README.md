# Deployment rounds

Working log for moving Qualifire onto Google Play (and later elsewhere), one round at a time, so decisions and how the plan evolves can be followed over time.

Same convention as `marketing/monetization/rounds/`:

- `roundN/ideas.md` holds Nathan's ideas, questions and decisions only. Agents never edit it.
- `roundN/review.md` holds Claude's review of that round (separate file, same folder).
- A new round starts only after the previous review has been read.

Baseline before round 1: `round1/review.md` (staged Play closed-testing plan), `../CURRENT-STATE.md`, `round1/questions-and-rulings.md` (Q1-Q10 answers, 2026-09-09/10).
