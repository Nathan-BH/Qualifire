Each state button freezes that sector's time over the ticking lap clock for ~2.5 s in its tier treatment and plays its real earcon (WebAudio, no files) — then the clock resumes, already further along.

D-019: every gate = one identical short buzz; the sound carries the tier — one soft note / rising fifth / rising arpeggio, one E-major family, nothing to count. Estimated: buzz + silence, grey dashed ~time, delta suppressed.

§2a handover: final gate = sector sound, 300 ms gap, then the lap voice (octave-doubled, no second buzz) as the LAP result takes the slot terminally, with its static tower-position chip (P2…) — no chip for an estimated lap, it does not rank. ~3 s later the board pushes and today's row slots in bottom-up (~700 ms, once, never on manual navigation).

§3b tower: P# · tier-coloured time · gap to P1 · date; today ~1.5× with the accent bar; ○ = archive-seeded ghost (D-018); a 19-deep session pre-scrolls so TODAY is on screen.

D-021: two equal buttons — declining is a race outcome. Keeping renders the all-purple REFERENCE SET frame: display-only, deltas suppressed, tower collapsed, and silent.
