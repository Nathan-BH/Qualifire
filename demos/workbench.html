Qualifire — route workbench

One page per route: the reference line, each gate as a draggable line with a live percent + metres + Google Maps readout, a way to promote a ride to be the reference, and a percentage slider for naming a specific point. Absorbs the gate-eyeball upgrade (perpendicular gate lines at true half-width, the crossing-point clouds, the 50 m arming window, the speed/stop labels — B-31) and the reference-promotion picker (B-42).
How to use / how to save

Move a gate: pick a route below, then drag its handle on the map. It snaps to the line live as you drag — the percent, metres and Google Maps link update as you go. Start and finish are draggable too, but moving either one breaks lap history, so they carry a standing warning.

Name a point: drag the percentage slider to any spot, type a label, press "name this point" — it's added to the list below, and can be deleted again before you save.

Promote a ride: drop a .gpx file onto the map (or use the file picker) to draw it over the reference line and, if you tick the box, propose it as the new reference.

Save: press Save — it downloads a JSON file. Move that file into data/analysis/workbench/; that folder is read at the start of every cycle.
