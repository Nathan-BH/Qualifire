# brand/ — visual identity assets

Librarian index · 2026-08-15. Rule: **scripts live at this level, outputs live
in subfolders.** Every image here is regenerated by a script — edit the
script, rerun, never hand-edit a PNG. Docs: `../BRAND.md` (story, principles,
motion language), `LOGO-RATIONALE.md` (per-concept design argument).

| Path | What | Regenerate with |
|---|---|---|
| `logos/` | 5 logo concepts, SVG (canonical, Inkscape-labelled) + PNG, `sheet.png` contact sheet | `make_logos.py` |
| `board/` | THE brand board: 12 panels (`board_01..12`) + `brandboard.png` montage — current identity applied to every surface incl. future race screens | `make_brandboard.py` |
| `palettes/` | Palette exploration: 6 single-composite trials (`palette_A..F.png`, `palette_trials.png`) + full 12-panel boards per surviving candidate (`<slug>/` + `brandboard_<slug>.png`) | `make_palette_trials.py`, `make_palette_boards.py` |

Related but elsewhere: earcon WAVs in `app/assets/earcons/` (with their own
`make_earcons.py`); the in-app theme is `app/src/ui/theme.ts` — when a palette
decision lands, theme.ts is the single place to change, then rerun the boards
with the same hexes.
