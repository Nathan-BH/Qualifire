# cycles/ — one report per completed cycle

`cycle-NNN.md` — a short, honest record of what that cycle did: what landed, what was
found by inspection, what token/tool-call cost each piece carried, and any near-misses
or blockers hit along the way. Written by the Team Principal at cycle close.

`cycle-024-briefs/` — the execution briefs dispatched to cycle 024's work-package
executors (one `WP-*.md` file per work package, plus `CONTEXT.md` for shared framing
and a token-usage reference file). Kept for the record; each brief describes the state
of the repo *at dispatch time*, not necessarily today's — later cycles' STATE.md is
what to trust for current state, not an old brief.

Read by: the Team Principal (writes these), any agent wanting cycle history, Nathan
(via `NATHAN-STATUS.md`'s "what just changed" first, and `STATE.md` next — these raw
reports are the detailed backing record, not the first place to look).
