Launch-animation option deck

Four concept mockups for new places the launch mark's motion language could show up, beyond the four spots already shipped (app-launch, START, tab-switch, final-gate). Each one below is a CSS/SVG web mockup of the idea — not the real React Native code in app/src/ui/launchChoreo.ts, which stays untouched by this deck.

Colours are the shipped palette only (app/src/ui/theme.ts) — ink, signature yellow, green, purple, near-black/near-white grounds. Nathan ruled 2026-09-08 that the palette itself is not changing, so nothing here proposes an alternate colour treatment; the toggle above just previews the existing day and night paddock grounds, both already in the app. Nothing on this page is wired into the app — react in one word per card, that's the whole ask.

Ink — identity stroke Yellow — neutral / gate Purple — fastest / earned only Green — above pool average

A Way lock-in

The live engine's tentative match on a way snaps to a verified, committed route mid-ride.

Trigger: soft match → verified (live engine) Runs: ~0.7s Loops: every 3.6s in this demo

B Purple-lap reveal

A sector or lap posts as the new fastest in the pool — the mark redraws itself in purple, the one tier the identity never wears by default.

Trigger: new purple (fastest) verdict Runs: ~1.5s Loops: every 4.2s in this demo

C Reference ride set

A blank-install rider's very first ride on a road becomes that way's reference route (NW-1). Neutral by ruling — no colour verdict, but it is real history from here on.

Trigger: first ride on a way saved (routeCreation.ts) Runs: ~2.4s Loops: every 5.2s in this demo
